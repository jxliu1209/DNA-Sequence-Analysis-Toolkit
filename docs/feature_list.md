# Feature List

This list tracks planned features by stage. The order starts with the simplest DNA concepts and moves toward more advanced analysis and future extensions.

## Stage 1 - DNA Fundamentals

- FASTA parsing
- DNA validation
- GC content
- Nucleotide frequencies
- Reverse complement
- Transcription
- Translation
- Codon usage
- Restriction enzyme search

## Stage 2 - Sequence Analysis

- ORF finding
- Motif search
- k-mer counting
- Consensus sequence
- SNP comparison
- Mutation simulation

## Stage 3 - Classical Algorithms

- Hamming distance
- Levenshtein distance
- Needleman-Wunsch
- Smith-Waterman
- Scoring matrices

## Stage 4 - Sequencing Data

- FASTQ parsing
- Quality score analysis
- Simple variant calling
- Multiple sequence alignment
- Phylogenetic tree generation

## Stage 5 - Future Extensions

- Biopython interoperability
- Visualization
- Genome annotation
- Primer design
- Command-line interface
- Web interface

The feature list is intentionally broad. It gives the project a long-term direction while still allowing the implementation to stay incremental.
